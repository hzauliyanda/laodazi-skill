# 历史冷门人物爆款生成器（春秋体）

模仿"我是历史其实挺有趣 / 春秋小历"公众号的爆款打法。严格按真实搜索素材写作，绝不靠模型记忆杜撰。

## 风格定位：这是什么，不是什么

本 skill 用春秋小历的笔法（纯线性、碎段落、文言平铺夹译），全文无小标题；只在顶部保留两处属于老达子自己的招牌：`文｜老达子` 与字数行。**开头、结尾都不套固定模板，按每篇的标题与素材另起。**

| 维度 | 本 skill（春秋体） | laodazi-history-writer（老达子常规体）|
|---|---|---|
| 结构 | **全文无小标题、纯线性**；不用贯穿意象 | 4-6 小标题 + 贯穿意象 |
| 段落 | **长短结合的碎节奏**：背景/解释铺大段，转折/判断单句一刀（别通篇单句） | 常规段落 |
| 人称 | "老达子"自称 + 称读者"**您**"、夹用"我们"（"我们看记载""我们知道"） | "大家" |
| 史料 | **白话叙事/分析为主体，文言只当锚点**：在关键转折甩一句**极短**的原文（多为一句话、七八个字），平铺在正文里（不用引用块）；**不必每处都翻译**，短引可只引不译直接白话接着说。约 4-6 处短引，**别扎堆连摆**，全篇文言原文占比约 3-4% | 白话为主，偶尔引原文 |
| 抬头 | `文｜老达子` + 引用块字数行 `> 本文共约…字`（**仅此一处用 `>`**） | 字数行不带引用块 |
| 开头 | **不固定句式**，按标题选切法（见下） | 较自由 |
| 结尾 | **不固定句式**，顺着本篇的意象/主线自然收住，配不配诗都行（见下） | "以古鉴今" |
| 类比 | **不用现代公司/职场类比** | 大量现代口语类比 |
| 字数 | 约 2300-2800 字，紧凑 | 约 3500 字 |
| 选题 | 冷门人物/事件、乱世富矿、祛魅反转 | 较宽泛 |

**触发本 skill 而非 history-writer 的信号**：用户说"像春秋小历那种""冷门人物反差""文言夹白话""碎段落娓娓道来"。

## 一、选题与标题：反差悬念 + 藏住人名

### 选题公式

`冷门人物/事件` × `一句话能说清的强反差` × （优先）`乱世`（元末、五代十国、南北朝、楚汉、安史之乱前后）

三条选题铁律：
1. **挑冷门、但故事性极强的人/事**。正史里只有寥寥几笔的人最好，冷门=蓝海，故事强=撑得起阅读量。
2. **永远在做祛魅 / 反转**。临时工掀翻一个省、最强的人反而被雪藏、最仁德的将领死于仁德、被当皇帝烧死的其实是个替身，每篇都打破读者预期。
3. **偶尔切制度史**（如一桩家产官司带出整套继承法），满足"原来古代这么精细"的认知颠覆。

### 标题公式（必须藏住人名）

- 低身份 × 高能量：「一个______，差点______」（例：一个临时工，差点灭了一个国）
- 极端反差：「______上简直天才，______上彻底没救」
- 因果倒错：「因为太太太______，所以______」（例：因为太太太强，所以被雪藏；因为长得太太太像皇帝，所以被活活烧死在城楼上）
- 对比勾人：「比______生猛，比______罕见」

**铁律**：标题绝不出现人名。卖的是"反差"，不是"人物"。用叠字、副词把情绪顶满（"太太太""彻底""简直"），像聊天不像书面语。

## 二、正文笔法

### ① 整体结构：招牌两行 + 纯线性正文（全文无小标题）

**全文不分小标题、不分节、不列点，一条线娓娓往下走。** 顶部只有两行属于老达子的招牌。骨架如下：

```
文｜老达子

> 本文共约 XXXX 字，阅读时长大约 X 分钟

[开篇：按标题选切法，几段把反差勾出来，自然带出主角名（不加标题）]

[正文：纯线性叙事，单句成段，设问推进，文言平铺夹译（全程不加任何小标题）]

[结尾：顺着本篇意象/主线自然收住，不套模板，配不配诗都行（不加标题）]

---
参考资料：……
```

要点：
- **抬头**：第一行 `文｜老达子`，第二行字数信息用引用块 `> 本文共约 XXXX 字，阅读时长大约 X 分钟`。这是全文唯一用 `>` 的地方。（标题文字由发布时另填，正文不重复写标题行。）
- **正文一路碎段落往下推，不设任何小标题**，靠设问句和单句成段制造节奏与停顿。
- **结尾不加任何标题**（不要 `# 老达子说` 这类小标题），直接顺着正文收口。

### ② 开头：不固定句式，按标题选切法

**别每篇都用同一句开场。** 先看这篇标题的反差点在哪，再挑最对味的切法。常见几种（也可自创）：

- **画面切入**（适合有强场景/强画面的标题，如"烧死在城楼上"）：直接把人扔进那个最炸的瞬间，再倒回去讲。
  > 公元前204年的一个夜里，荥阳城东门外，火光冲天。火里绑着一个穿着天子衮服的人……这个被当成皇帝、活活烧死在乱军里的人，叫纪信。
- **时间地点直切**（适合事件型、制度型）：像范孟、田县丞那样，上来就甩年代、地点、一个不起眼的小官，平铺开场。
  > 公元1339年，是元朝末年……在汴梁城里，有一个叫做范孟的官员，职位不高，是一个掾吏。
- **名将反衬**（适合"群星里的冷门人"）：先列同时代的耀眼人物，再"但今天要讲的不是他们"，抛一串矛盾，最后点名。
  > 元末明初，群雄逐鹿，猛将如云……但作者今天讲的不是他们……此人大字不识一个，却让无数读书人为之效力……这个人，就是胡大海。
- **设问/反差直问**：用一个"您可能不信"的问句把读者勾住。

无论哪种，**末尾自然带出主角名**（"这个人，叫XXX""他叫XXX"），别在标题和正文里提前剧透人名以外的反转。

### ③ 第一人称"老达子"，称读者"您"，夹用"我们"

制造一个正在跟你唠、会承认自己局限的叙述者：
- "您说他混得有多惨？" / "说出来您都不信，只剩下五十公里。"
- "我们看《元史》卷四十五的记载……" / "我们知道，传统的农民起义大多是流动作战。"
- "老达子估计这蜡丸应该不小……" / "有关这段的记载实在太少了，老达子不能胡说八道。"

"您"主打亲切，"我们"主打一起看史料。**遇到史料空白处，明确说"查无所考""老达子估计""学界仍有争论"，绝不编造**。

### ④ 文言原文：当锚点用，别当主菜（平铺不用引用块）

**文言是钉子，白话叙事和分析才是墙。** 一句短原文，是这个号区别于地摊野史号的信任锚点，但它是**香料，不是主食**。看真号那四篇就明白：全篇白话娓娓道来，文言只在关键处零星钉几下，每下都极短。**最容易写坏的就是文言钉太密、单句太长、还每句必翻译，那一篇就糊成了文言注疏，不是春秋小历。**

四条铁律：

1. **短**。引文越短越好，**一句话、七八个字最佳**。真号的常态是：
   - `《元史》卷四十五：自是山东郡邑皆陷。`（7 字）
   - `于是杀孟端于外。`（7 字）
   - `《明史》：惟毛贵稍有智略。`（6 字）
   超过二十来字的长引，能砍则砍、能截则截。

2. **可以只引不译**。短到一看就懂的，**直接白话接着说，不用翻译**。真号大量这么干，"我们看《明史》中的评价：惟毛贵稍有智略。" 后面就没有翻译了。**不要每处都"原文+翻译"成对出现**，那是把篇幅生生翻倍、把文言体感顶上去的元凶。只有较费解的长句才配一句白话。

3. **别扎堆**。一处转折钉一句就够，**别连着摆三四处"原文+翻译"**。两处引文之间要隔开足够的白话叙事。

4. **总量克制**。一篇约 4-6 处短引，**全篇文言原文加起来占比约 3-4%**（向毛贵、范孟那几篇看齐，别向超密的样板看齐）。

格式：原文直接平铺在正文里，单独成段，前面用"我们看记载""《XX》卷X 里写"之类引一句带出，交代书名+卷数。不用 markdown 引用块 `>`。带翻译时紧跟一段白话；不带翻译时直接白话续写。例（只引不译）：

```
我们看记载。

《元史》卷四十五：自是山东郡邑皆陷。

元朝在山东的统治，就像多米诺骨牌一样接连倒下。
```

带翻译只留给较长、较费解的句子，例：

```
《资治通鉴》卷一八五：天下名义，非妇人所知！

天下的大义名分，不是你一个妇道人家懂的。
```

### ⑤ 长短结合：碎节奏，但别通篇单句

**最容易写坏的地方：别每段都一句话。** 真文章是长短交替：背景、铺垫、解释、层层累加这类，敢铺成完整的大段，一段里好几句连着走（看范孟开篇交代身份那一长段，毛贵"首先…然后…"讲屯田那几大段）；到了关键转折、下判断、抖包袱、留悬念，再单句成段、一句一刀。通篇单句会显得碎、显得喘，长短交替才有节奏。

- 长段铺陈（连着几句）：汉三年，公元前204年，楚汉相争已经进入了第三个年头，刘邦和项羽，就在一座叫荥阳的城里死磕。荥阳这地方为什么要命？因为它的背后就是敖仓，秦朝留下来的天下第一大粮仓，谁占了荥阳、扼住敖仓，谁就不愁吃。
- 短句一刀（单独成段）："可项羽不傻。" / "刘邦慌了。" / "是他坐的那辆车。" / "项王，烧杀纪信。"

关键转折单独成段，制造停顿。口语设问句隔几段抛一个，把长文切成一段段悬念："怎么说？""他靠什么？""为什么会这样？"

### ⑥ 结尾：不固定句式，顺着本篇收住

**别每篇都"配诗+金句"。** 看这篇的脊梁是什么，顺着它自然收口。真文章里几种收法都用过：

- **一句比喻收住**（范孟）：把元朝灭亡比作一扇门，"范孟就是那个最早找到钥匙的人……他让所有人都看到了，这扇门啊，有条缝。"
- **引一句名言再落地**（田县丞）：引沈家本"力求情法两尽"，最后"于情，于法，已然两尽了。"
- **配一首诗再感慨**（毛贵、胡大海）：先来一首七绝（自拟或贴合的旧诗，每句单独成行），再几句把人拔到历史。
- **抓住贯穿意象一锤**（纪信，全篇是"火"）：不配诗，直接问"项羽那一把火，到底烧掉了什么"，层层递进收到"真正烧不掉的，从来不是一张像不像皇帝的脸"。

配诗与否、用不用名言，**取决于这篇有没有合适的诗/句**，硬凑反而出戏。结尾不加任何小标题。

### ⑦ 文末参考资料（拉开档次的关键）

正文后用 `---` 隔开，附参考资料，**务必含 1-2 篇知网硕博论文 / 期刊论文**，给人"认真查过"的印象：
```
---

参考资料：

《元史》

《学海类编》

李倪倪.元末义兵新探.山东大学,2022
```

## 三、硬性禁忌

- ❌ **不加任何小标题**（包括 `# 老达子说`），不分节编号，不列点；全文只在顶部有 `文｜老达子` 和字数行两处招牌
- ❌ **文言引文不用引用块 `>`**（`>` 只给字数行用），原文平铺在正文里
- ❌ **文言别钉太密、太长、句句必译**：短引为主（一句话最好），可只引不译，别连摆扎堆，全篇文言原文占比约 3-4%。白话叙事/分析才是主体，文言只是锚点
- ❌ **不用现代公司/职场类比**（用户硬性偏好，见记忆 feedback-no-corporate-analogy）。能用历史本身的词（小吏、刀笔吏、节度使）就别用现代词
- ❌ 不用"综上所述/不可否认/总而言之/由此可见"这类书面 AI 腔（注意：口语化的"首先…然后…""值得注意的是"按真文章那样自然地用是可以的，别堆砌即可）
- ❌ **别滥用破折号（——）**：这是最容易泛滥的标点，一篇里出现三五处就显得拖、像 AI 腔。绝大多数破折号都能换掉：解释说明用逗号或括号，引出文言原文用句号或冒号（写"我们看记载。""《元史》卷四十五里写："），转折停顿直接用句号断开成两句。全篇破折号尽量不超过 2 处，能没有最好
- ❌ 标题不出现人名
- ❌ 史料空白处不编造，明说"查无所考""学界仍有争论"
- ❌ 开头、结尾不套固定模板，每篇按标题与素材另起

## 工作流程（严格分步执行，绝不一次性生成）

**核心原则**：先搞准事实，再写。所有史料必须来自真实搜索，不靠模型"回忆"。

### 第1步：查证调研（搜全部素材，WebSearch）
先把标题关键词拆成 2-3 条素材线，输出每条线的：关键词 / 待回答问题 / 搜索方向。再一次性把素材搜齐，**全程只查正史、实录、知网论文，不查自媒体；空白处明说"查无所考"**：
- **原典原文**：搜事件原始文本（正史具体卷数、笔记原文），拿到关键场景描写和人物原话。**验证主角身份**，别想当然，真正的主角是最能体现标题反差的那个人。
- **制度/正史史料**：搜《史记》《元史》《宋史》《明史》等正史、实录原文，提取关键条文、标注卷数，建立立论基础。
- **评点 / 学术论文**：搜名家评点和**知网硕博/期刊论文**（文末参考资料来源，也增加分析深度），记录论文作者/标题/单位/年份。

### 第2步：定主线、开头切法、收尾方向
- 这些素材里，**最大的反差点 / 祛魅点是什么**？这就是文章的脊梁，也是开篇要勾住的悬念。
- **本体纯线性、无小标题**：把素材按时间线排成一条往下推的故事链，规划好几处设问句和单句成段的转折点当"节奏停顿"（替代小标题的作用）。
- **开头切法**：按标题挑切法（画面/时间直切/名将反衬/设问），别套固定句式。
- **收尾方向**：看本篇脊梁，定怎么收（比喻/名言/配诗/贯穿意象），有合适的诗再配，没有就别硬凑。
- 标出哪几处钉文言短引（约 4-6 处，引文要极短、能只引不译就别译、别扎堆），其余靠白话叙事推进；全篇文言原文占比控制在约 3-4%。

### 第3步：写正文 + 自查修正（约2300-2800字）
严格基于前两步的真实素材与主线，按春秋体笔法写：
- 抬头：`文｜老达子` + 引用块字数行 `> 本文共约 XXXX 字，阅读时长大约 X 分钟`
- 开篇（不加标题）：按选定切法勾出反差，自然带出主角名
- 主体：**纯线性，不加任何小标题**，单句成段、设问推进、文言平铺夹译（每处引文交代书名+卷数，紧跟白话翻译，不用 `>`）
- 结尾（不加标题）：顺着本篇意象/主线自然收住
- 文末：`---` + 参考资料（正史 + 知网论文）

**输出格式**（注意：无 YAML 元数据；全文无小标题；只有字数行用 `>`；文言引文平铺）：
```
文｜老达子

> 本文共约 XXXX 字，阅读时长大约 X 分钟

[开篇：按标题切法勾出反差 + 自然带出主角名，不加标题]

[正文：纯线性，单句成段，设问推进。文言引文这样写：]

《XX》卷X：文言原文……

白话翻译……

[继续往下，全程不加小标题，结尾顺着主线收住……]

---
```
