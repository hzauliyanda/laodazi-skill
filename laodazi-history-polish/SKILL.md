# 老达子风格润色器

对已有历史类文章进行润色，使其符合"老达子"的写作风格。

## 使用方法

```
/laodazi-history-polish <文件路径>
```

润色完成后自动保存，覆盖原文件。

## 文件读写规则（重要）

**必须使用脚本读取和写入 markdown 文件**，不要用 Read/Write 工具直接操作。

**读取文件**：
```bash
bun run ~/.claude/skills/laodazi-history-polish/scripts/polish.ts read <文件路径>
```

**写入文件**（通过 stdin 管道传入内容）：
```bash
cat <<'HEREDOC' | bun run ~/.claude/skills/laodazi-history-polish/scripts/polish.ts write <文件路径>
<润色后的文章内容>
HEREDOC
```

**原因**：Read/Write 工具在处理中文内容和中文标点符号（如""）时可能出现编码偏差，脚本使用 Buffer + TextDecoder/TextEncoder 确保 UTF-8 编码正确处理。

## 润色检查清单

按以下顺序逐项检查并修改：

### 第一步：标点符号（最优先）

**所有标点必须使用中文标点**，尤其是引号。

| 错误 | 正确 |
|------|------|
| "" （英文双引号） | ""（中文双引号） |
| '' （英文单引号） | ''（中文单引号） |
| : （英文冒号） | ：（中文冒号） |
| , （英文逗号） | ，（中文逗号） |
| ; （英文分号） | ；（中文分号） |
| ! （英文感叹号） | ！（中文感叹号） |
| ? （英文问号） | ？（中文问号） |
| () （英文括号） | （）（中文括号） |

**破折号（——）要节制使用**：能用逗号、冒号、句号的地方就不要用破折号。每篇文章最多保留5个，超过的必须替换。常见替换：
- 解释说明：用逗号或括号代替（如"他——一个逃犯——竟然称帝了"改为"他，一个逃犯，竟然称帝了"）
- 话题转折：用句号断开或用"但是""不过"连接
- 总结收束：直接用句号

**引号（""）严格限制使用**：整篇文章的引号数量**不得超过5对**。这是老达子风格的硬性要求。
- 统计范围：只统计正文内容的引号，不含史料引用块（`>` 引用格式）
- 使用优先级：史料原文引用 > 特定术语强调 > 普通强调
- 替代方案：能用冒号、逗号、破折号的地方就不用引号；能用间接引语就不用直接引语
- 示例对比：
  - 差：他说："我不想活了。"
  - 好：他说他不想活了。
  - 差：这个概念叫"合法性焦虑"
  - 好：这个概念叫合法性焦虑
  - 差：人们叫他"掘墓人"
  - 好：人们叫他掘墓人

### 第三步：文章结构与格式

检查并调整结构和格式：

**格式规范（必须遵守）：**

1. **标题层级**：所有章节标题统一使用 `#` 一级标题（`# 前言`、`# 一、xxx`、`# 老达子说`），不要用 `###` 或 `##`
2. **阅读信息格式**：字数和阅读时长必须用 `>` 引用格式包裹，例如：
   ```markdown
   文｜老达子

   > 本文共2523字，阅读时长大约6分钟
   >
   ```
3. **前言过渡语**：前言末尾必须加入"今天老达子就来跟大家聊聊"这类过渡句，并以"～"结尾自然引出话题。**前言开篇和转折必须自然**，详见下方"前言写法指南"
4. **文头独立行**："文｜老达子"单独一行，不加任何格式标签

**板块要求：**

| 板块 | 要求 |
|------|------|
| 文头 | "文｜老达子"单独一行 + `>`引用格式的字数和阅读时长 |
| 前言 | **前言的核心任务是用最短的话抓住读者。不管原文开头是诗词还是白话，引用之后的接法不能走AI模板（双比喻、三段反转、对仗对比等）。** 1-2段内抛出核心悬念，末尾加"今天老达子就来跟大家聊聊……～"过渡语。详见下方"前言写法指南" |
| 正文 | 3-5个主题小节，每个小节用 `#` 一级标题，层层递进 |
| 老达子说 | **⚠️ 强制约束：绝对不超过3段**（能2段更好）。简短收尾，直击要害，说清一个核心判断就收。一句锋利的总结、一个反问、或一句留白结尾即可，干净利落。**原文再长也必须压缩，无例外。** |

**结尾硬约束（老达子说，⚠️ 最高优先级，必须遵守，无例外）：**

1. **段落数 ≤ 3**（能 2 段更好）。原文结尾再长也要压到 3 段以内，**绝不超段，绝无例外**。
2. 只说**一个**核心判断，不贪多、不面面俱到。
3. 禁止模板化收尾：不要"排比三连 + 反转 + 金句"、不要对仗金句（如"安全感得靠真本事挣"）、不要"真正的X，不需要Y"这类万能升华模板。
4. 用句号收住，不要感叹号或省略号拖尾巴。

**前言写法指南（重要）**

润色前言时，最常见的毛病就是机械地走"引用一段话 → 但翻开XX书 → 真相是"的三段式。这种写法用多了，读者一看开头就知道后面要说什么，完全失去吸引力。

**核心原则：前言要像你在饭桌上跟朋友聊起一个八卦，不是在写论文。**

#### 一、前言开篇：直接、自然、像人话

**前言的核心任务是用最短的话把读者抓住。** 好的前言要像你跟朋友聊天时甩出一个八卦，而不是写论文。

**禁止使用的AI模板**（不管开头是什么形式，以下套路一用就像AI写的）：
- ~~引完古诗后接双比喻：~~ "历史这东西，看着像A，其实更像B" — AI标志性句式
- ~~三段反转模板：~~ "咱们总爱看……觉得那才是……可真实的……" — 一眼AI
- ~~对仗对比：~~ "昨天的生死兄弟，明天可能就成了棋盘上的棋子" — 太工整，真人不会这么说话
- ~~高频情感词：~~ "脊背发凉""让人唏嘘""发人深省" — AI标配反应
- ~~万能哲理感慨：~~ "在时间的风吹雨打和权力的炙烤下，尤其脆弱" — 假大空

古诗引用本身没问题，如果跟文章主题确实贴切，可以保留。关键是引用之后的接法不能走模板。

**第1步：素材优先原则 —— 角度跟着素材走，不查表按顺序拿**

不要按固定偏好挑开篇方式。先判断这篇文章**最硬的资产**是什么，再选匹配的角度：

| 文章最硬的资产 | 优先考虑的角度 |
|----------------|----------------|
| 有惊人的数字/账目 | 数字冲击、一笔账开头 |
| 有史书里的无名小人物 | 在场小人物的眼睛 |
| 史料本身有矛盾或空缺 | 史料的空白处开刀 |
| 主角有费解的怪癖/反常行为 | 反常动作不解释 |
| 结局与开局反差巨大 | 从结局倒着讲、两条时间线对撞 |
| 有一件贯穿全文的物件/法令/文书 | 一件物品当钥匙 |
| 主题连着今天还活着的词/习俗/地名 | 后世的回响倒着挖 |
| 大众有牢固的错误认知 | 认知反转、反直觉提问 |
| 有强烈的戏剧性画面 | 场景切入 |

**角度库**（无优先级，按素材选用）：

| 角度 | 用法 | 例子 |
|------|------|------|
| **从结局倒着讲** | 先给尘埃落定后的画面，再问怎么走到这一步 | "隋大业年间，长安城里有个前朝皇帝，天天喝得烂醉。别的亡国之君坟头草都三尺高了，他不但活着，还当上了宰相。" |
| **一件物品当钥匙** | 从一样东西讲起：法令、酒盏、白绫、城门，物件背后带出人 | "南京故宫的档案里留着一份名单，四十六个名字，全是年轻女子。名单立档的日期，就是朱元璋咽气的那天。" |
| **在场小人物的眼睛** | 从史书里只有半句话的旁观者视角进入：太监、老兵、书记官 | "城破那天，清军里有个书记官负责清点降人。他在城门口站了一整天，一个跪着出来的都没等到。" |
| **史料的空白处开刀** | 从史书不敢写、漏写的地方讲起，悬念在缺席本身 | "《明实录》把朱元璋临终那几天记得事无巨细。唯独闰五月初十那天晚上，宫里死了几十个人，实录上一个字都没有。" |
| **两条时间线对撞** | 同一年/同一天，两件不相干的事并置，反差自己长出来 | "公元280年，洛阳的晋武帝收到降表的同一个月，建业的老百姓终于敢往那条水道边上走了。" |
| **一笔账开头** | 用一份冷冰冰的账目切入：谁付的钱、付给谁、买了什么 | "打赢那场仗，朝廷赏了他三百户食邑。二十年后，杀他全家用的刀，也是朝廷出的钱。" |
| **后世的回响倒着挖** | 从今天还活着的一个词、地名、习俗讲回去 | "绿帽子这个词你天天听，可你多半不知道，它真跟一条朝廷法令有关。" |
| **反常动作不解释** | 只给动作，不给动机，解释欠着读者就得往下读 | "最能打的那个将军，每次上阵前都先跟主帅讨价还价，谈不拢就不肯出力。" |
| **认知反转** | 大众以为A，其实是B（注意：这是目前用得最滥的角度，最近几篇用过就必须避开） | "卧薪尝胆这四个字没人不知道。可从头看到尾，勾践只有尝胆，压根没有卧薪。" |
| **直接摆讽刺** | 文章有核心讽刺点 | "一百多年前，列强排着队从大清身上割肉。一百年后，当年拿走最多赔款的那几个国家，得的还是当年大清的病。" |
| **场景切入** | 有戏剧性事件，靠刺激画面抓人 | "公元1449年的一天，北京城的朝堂上，一群文官当场把锦衣卫的老大活活打死了。" |
| **数字冲击** | 涉及大规模事件 | "一个案子，杀了三万人。不是战场上死的，是一个一个审出来的，杀出来的。" |
| **反直觉提问** | 大众有固定认知 | "你知道明朝死得最惨的一批人，不是战场上的武将，而是坐在办公室里写公文的文官吗？" |

**第2步：移植测验（写完前言必做自查）**

把写好的前言里的专有名词（人名、朝代、地名、事件）全部换成另一篇文章的，如果句子依然成立，说明这是可移植的模板，**必须重写**。"大家都以为X，其实Y""历史上最X的Y"都是典型的可移植句式。好的开头应该长在只属于这篇文章的细节上，换了名词就不成立。

**如果原文开头用了古诗但接法自然**，可以保留。判断标准：去掉诗词后面的AI模板（双比喻、三段反转等），换成直接切入核心话题的写法。如果原文开头去掉古诗后反而更有冲击力，那就果断砍掉古诗。

#### 二、转折要自然，严禁机械套路

**禁止使用的转折方式**（这些已经用烂了，读起来像模板）：
- ~~"但当你翻开《明史》……"~~
- ~~"翻开尘封的史书……"~~
- ~~"拨开历史的迷雾……"~~
- ~~"回到《xx史》的字里行间……"~~
- ~~"当我们放下对X的想象……"~~
- ~~"然而，事实真的如此吗？"~~
- ~~"但历史的真相远比这残酷"~~

**正确的做法：不要刻意制造"反转感"，而是让信息自然流动。** 具体方法：

1. **用细节本身制造反差**，而不是用"但是"硬掰：
   - 差："很多人觉得锦衣卫很帅。但翻开《明史》，真相远比这残酷。"
   - 好："飞鱼服、绣春刀，影视剧里的锦衣卫一个比一个帅。可真实的锦衣卫指挥使马顺，是被一群文官在朝堂上活活打死的。"

2. **用提问代替陈述转折**：
   - 差："然而，事实真的如此吗？"
   - 好："三万人里，有几个是真正想造反的？朱元璋不在乎。他要的不是真相，是一个能让他动手的理由。"

3. **直接用画面或数字切入，不要先铺垫再推翻**：
   - 差："人们常说胡惟庸案是正义的审判。但真相是……"
   - 好："洪武十三年，一个宰相倒台了。然后，三万人跟着他一起死。这个数字里，有开国功臣，有地方官员，有跟胡惟庸连面都没见过的小吏。"

#### 三、前言必须制造悬念

前言的最后一个功能，就是让读者忍不住往下看。好的悬念不是故弄玄虚，而是抛出一个读者暂时无法回答的问题。

**制造悬念的技巧**：
- **抛出反常结果**："这些人手里都握着皇帝的刀，可他们几乎没一个得了好死。唯独一个人例外。"
- **制造信息差**："朱元璋晚年干了一件事，这件事让后来所有读史的人都不寒而栗。"
- **用提问代替结论**："但你知道后面怎样了吗？" — 简单一句话，读者就得往下看
- **点到为止**：提到一个关键信息但故意不说完，让读者必须往下读才能知道答案

#### 四、前言过渡句要精简

末尾的过渡句直接切入话题，去掉填充话术：
- 直接说"今天老达子就来跟大家聊聊，[具体话题]～"
- 不要加"抛开X不谈""只翻Y档案""回到Z的字里行间"这类废话

如果原文缺少前言或老达子说板块，要补上。

### 第四步：写作技法

检查以下技法是否充分运用：

#### 祛魅反转（最核心）
每个小节至少有一次"大众以为A → 其实是B"的反转。如果原文只是平铺直叙讲历史，要加入反转结构。常见反转模式：
- "很多人以为……但实际上……"
- "网上有很多说法……但这其实是……"
- "教科书里通常会提到……但如果你去翻看……"

#### 史料引用 + 白话翻译
- 引用史料原文后，必须紧跟口语化翻译
- 例：引用"白骨露于野，千里无鸡鸣"后，接"这就是说一百个人里只有一个活了下来"
- 史料用引用格式 `>` 呈现

**出处精简（重要）**：整篇文章的史料出处标注**不超过5处**，多余的一律删掉。
- 删掉的出处类型：引用块末尾的"——《XX史》""——《XX·卷XX》"、正文中的"据《XX》记载""《XX》中写道"等
- 保留优先级：冷门史料（读者不知道出自哪里的） > 与大众认知有反差的引用 > 常见正史引用（《史记》《资治通鉴》《明史》等大家耳熟能详的，优先删）
- 删除方式：直接去掉出处标注，让引文自然融入叙述，不要留下"据记载""史书上说"这类空壳过渡
- 示例：
  - 差：`> 白骨露于野，千里无鸡鸣。——曹操《蒿里行》`
  - 好：`> 白骨露于野，千里无鸡鸣。`
  - 差：据《明史》记载，洪武十三年正月，丞相胡惟庸以谋反罪被诛。
  - 好：洪武十三年正月，丞相胡惟庸以谋反罪被诛。

#### 现代类比：不要使用

默认不用任何现代类比。不管是公司/职场类比（CEO、公司、打工人、老板），还是当代生活、科技、游戏、网络词类比（远程微操、开了个外挂、编制内办事员、教科书级、降维打击），一律不要。

历史文章的读者要的是历史代入感，现代类比会让文章瞬间出戏，破坏沉浸感。润色时主动清除：原文里已有的现代类比，能删则删；删不掉的，换成历史语境的词，或改成平实直白的表述。

优先用历史语境本身的词：能用历史本身的词（小吏、刀笔吏、节度使、流民、屯田）就别用现代词；要打比方，就用同时代的事物（同朝代的器物、制度、生活）。

#### 画面感场景
不要用抽象概括，要写具体画面，每篇至少2处：
- 差："机枪威力很大"
- 好："那枪口喷出的火舌，远处一棵合抱粗的大树在几秒钟内被拦腰打断"

#### 短句炸弹
每篇至少2个独立成段的情感金句：
- "那不是数字，那是一条条鲜活的生命。"
- "一切真理，最终都必须讲方言。"

### 第五步：语言风格

| 要求 | 说明 |
|------|------|
| 口语化叙述 | 用"咱们""你看""你想想""你看看"拉近距离 |
| 读者带入 | 多用"你"，少用"人们""大众" |
| 节奏感 | 长短句交替，关键时刻用极短句收束 |
| 适度幽默 | 偶尔用网络语调节气氛，但不要喧宾夺主 |
| 波浪号 | 适当使用"～"增加语气亲和感 |
| 情绪曲线 | 开头轻松/好奇 → 中间逐步加重 → 结尾升华 |

### 第六步：价值观底色

检查文章是否体现了以下价值观（不要刻意添加，而是确保没有违背）：

- **反浪漫化**：不美化历史，揭露盛世背后的残酷
- **反教条**：强调从实际出发，反对脱离实际的照搬
- **人文关怀**：关注被历史碾压的个体

## 润色案例

### 案例：铺垫式引出太啰嗦

**问题识别**：文章经常用"要搞明白X，咱们得先看懂Y"或"想要理解X，就得先看看Y"这类句式来引出话题，后面还喜欢跟一句"这里面藏着……"来制造悬念。这种写法看似在铺垫，实际上只是在拖延信息到达读者的速度，读多了显得套路。

**润色原则**：不要先铺垫再说正事，直接把读者带到要讨论的话题面前。用"我们先来看看""先说""先搞清楚"这类简洁的过渡句直接切入。

**案例对比**：

差（原文）：

> 要搞明白明朝为什么会崩，咱们得先看懂它的底层经济架构。这里面藏着一个天大的BUG。

好（润色后）：

> 我们先来看看明朝的底层经济架构。

**更多示例**：

| 差（铺垫式） | 好（直接切入） |
|---|---|
| 想要理解这个问题，咱们得先搞清楚一个基本前提 | 先搞清楚一个基本前提 |
| 要说明白这件事，就得先看看当时的背景 | 先看看当时的背景 |
| 要搞懂这个人为什么这么做，得先了解他面对的局面 | 先了解他面对的局面 |
| 想要知道答案，我们必须回到那个时代 | 回到那个时代 |
| 这背后的原因很复杂，但核心就一个 | 核心就一个 |

**改造要点**：

1. 删掉"要搞明白/想要理解/要说明白"这类铺垫句头，直接说正事
2. 删掉"这里面藏着……"这类刻意制造悬念的尾巴，让信息自己说话
3. 用"先来看看""先说说""先搞清楚"等简洁过渡句引出话题
4. 如果后面的内容本身就有冲击力，不需要额外的铺垫和悬念包装

**识别信号词**：凡是看到"要搞明白X，咱们得先……""想要理解X，就必须先……""要说明白这件事……"这类句式，都应该考虑砍掉铺垫，直接切入。

### 案例：编号式分析框架太生硬

**问题识别**：当文章需要分析多个原因或层次时，作者常用"第一层/第二层/第三层"或"其一/其二/其三"的编号结构，还喜欢给每层贴一个学术化标签（如"文化盾牌""信仰纽带""安全阀门"）。这种写法读起来像讲义提纲，不像在讲故事。

**润色原则**：把编号标签换成自然的叙述过渡，把学术概括词删掉，让逻辑像聊天一样流动起来，而不是被切割成清单。

**案例对比**：

差（原文）：

> 第一层，它是一面文化盾牌。苏联解体后的文化真空中，图瓦人迫切需要一个符号来重塑民族认同……
>
> 第二层，它是一条信仰纽带。苏联时期被严厉禁止的藏传佛教，在90年代后迅速复兴……
>
> 第三层，它是一个安全阀门。今天的图瓦共和国，经济上是俄罗斯联邦中最贫困的地区之一……

好（润色后）：

> 先说最直观的。苏联解体之后，图瓦人面对一个特别尴尬的问题：怎么证明自己是图瓦人，不是俄罗斯人？……
>
> 但这还只是表层。再往下挖，跟信仰有关。苏联时期被严厉禁止的藏传佛教，到了90年代迅速复兴……
>
> 还有一层，最现实也最无奈。今天的图瓦共和国，经济上是整个俄罗斯联邦里最穷的地方之一……

**改造要点**：

1. 去掉编号标签（第一层/第二层/第三层 → 先说最直观的/但这还只是表层/还有一层）
2. 去掉学术化概括词（文化盾牌/信仰纽带/安全阀门 → 直接说事）
3. 用口语过渡句连接各层，形成自然的递进感
4. 每个层次内部用提问或场景切入，不要直接给结论

**识别信号词**：凡是在正文分析段落中看到"第一层/第二层""其一/其二""首先/其次/最后"（用于并列分析而非时间顺序叙事时），都应该考虑改造成自然叙述流。

**注意区分**：如果"先是A，然后B，最后C"是在描述有时间先后的事件序列（如苏联先改文字、再灭宗教、再改生活方式），这种时间顺序的列举是可以保留的，不算"编号式框架"问题。

### 案例：数量渲染式强调要删掉（"几个字""X个大字""X句话"）

**问题识别**：AI写历史文章爱用"数量+字/大字/句话"来渲染某个文字内容的分量，制造廉价震撼。这类写法的共同特征是：数量词后面都跟着具体内容（文字、口号、原话），数量纯粹是凑气势的冗余，删掉不丢任何信息。常见形态：
- "写下十个大字"
- "留下了八个大字"
- "题了四个字"
- "短短几个字""寥寥几个字""这几个字""就那么几个字""短短的几个字"
- "说了三句狠话"

**凡是这种渲染式的数量修饰，一律删掉，直接接内容，没有例外。**

**润色原则**：把"X个字""X个大字""X句话"这部分整个删掉，让内容自己出来。不要用数量来抬分量。

**案例对比**：

差（原文）：

> 他含恨写下十个大字：还我河山。

好（润色后）：

> 他含恨写下：还我河山。

**更多示例**：

| 差（带数量渲染） | 好（删掉数量） |
|---|---|
| 写下十个大字 | 写下 |
| 留下了八个大字 | 留下了 |
| 题了四个字 | 题了 |
| 短短几个字，道尽一生悲凉 | 这话道尽一生悲凉 |
| 寥寥几个字，分量重得吓人 | 这话分量重得吓人 |
| 史书上就那么几个字 | 史书上就留下这么一句 |
| 说了三句狠话 | 说了 |

**改造要点**：

1. "X个字""X个大字""X句话"这类数量修饰，只要后面跟着具体内容，**全部删掉**，直接接内容
2. 字面的"几个字"也一样：短短几个字、寥寥几个字、这几个字、就那么几个字、短短的几个字，一处不留
3. 删完通读，确认全文没有"X个字""X个大字""X句话"残留

**⚠️ 边界：事实数字必须保留，绝对不能删**

这条规则只删"渲染式数量修饰"，不删"事实数字"。判断标准只有一条——**删掉后会不会丢核心信息**：

- **渲染式（删）**：后面跟着具体内容，数量是冗余强调
  - 写下十个大字：还我河山 → 写下：还我河山（内容还在，不丢信息）
  - 留下八个字：莫须有 → 留下：莫须有
- **事实数字（留）**：数字本身就是核心信息，删了就是失真
  - 杀了三万人、坑杀降卒四十万、走了八百里、在位三十年、活到七十岁、相隔二百年——这些数字是史料事实，**绝对保留，一个字都不能动**

**识别信号词**：看到"个字""个大字""句话"这几个字眼，先看后面有没有跟具体内容；跟了具体内容的，删掉数量修饰，直接接内容；如果是伤亡、人口、距离、年限这类事实数字，保留不动。

## 常见问题

### 润色后文章变得太"水"了
口语化不等于口水化。保留信息密度，只是换一种更亲切的表达方式。史料引用、数据支撑、逻辑推演这些干货不能丢。

### 不知道某个词该不该替换
判断标准：想象你在跟一个朋友面对面聊天，你会自然地说出这个词吗？如果不会，就换掉。

### 引号到底用哪种
用中文双引号""，不要用英文双引号""，也不要用「」。

### 润色时改了太多内容怎么办
润色的目标是调整风格，不是重写文章。保留原文的核心观点、论据结构和史料引用，只改表达方式。
