# 视频口播稿生成器

自动将Markdown文章转换为适合视频录制的口播稿，并生成多个爆款标题供选择。

## 快速开始

```bash
# 使用skill
/laodazi-video-copywriting 文章路径.md

# 输出文件：文章路径-口播稿.md
```

## 功能特点

- ✅ 自动生成500字左右的视频口播稿
- ✅ 开头设置强力钩子，抓住观众注意力
- ✅ 口语化表达，适合视频录制
- ✅ 生成5个爆款标题供选择
- ✅ 逻辑清晰，起承转合自然流畅

## 输出格式

生成的MD文件包含：

```markdown
# [最佳标题]

[口播稿正文 - 500字左右]

---

## 5个爆款标题供选择

1. [标题1]
2. [标题2]
3. [标题3]
4. [标题4]
5. [标题5]
```

## 口播稿结构

1. **开头钩子**（50-80字）：制造悬念，抓住注意力
2. **正文内容**（约350字）：讲述故事，传递核心观点
3. **结尾升华**（50-70字）：总结观点，引发思考

## 使用场景

- 制作短视频内容
- 录制音频节目
- 直播脚本准备
- 知识分享视频

## 与其他skill配合

```
/laodazi-history-writer [选题]        # 生成历史文章
/laodazi-markup 文章.md               # 智能标注
/laodazi-video-copywriting 文章.md    # 生成口播稿
/laodazi-post-to-multi-platform 文章.md  # 发布到平台
```

## 注意事项

- 口播稿总字数控制在500字左右（约2-3分钟口播时长）
- 使用口语化表达，避免书面语
- 多用短句，控制句子长度
- 标题要有吸引力和传播性
- 字数控制在10-12字
