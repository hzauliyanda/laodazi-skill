# 视频口播稿生成器

自动将Markdown文章转换为视频口播稿，并生成爆款标题。

## 核心功能

- 📝 **智能转换**：将文章改写为500字左右的口播稿
- 🎣 **爆款标题**：自动生成5个10个字左右的爆款标题
- 🎤 **口播优化**：口语化表达，适合视频录制
- ⚡ **快速输出**：一键生成，直接保存为MD文件

## 使用方法

### 生成口播稿

```
/laodazi-video-copywriting 文章路径.md
```

**执行流程：**
1. 读取原始文章内容
2. 智能分析文章核心观点
3. 生成500字左右的口播稿（带钩子开头）
4. 生成5个爆款标题供选择
5. 保存为 `原文件名-口播稿.md`

**示例：**

```bash
/laodazi-video-copywriting /Users/xxx/article.md
# 输出：/Users/xxx/article-口播稿.md
```

## 口播稿结构

### 1. 开头钩子（前50-80字）

**作用：** 制造悬念，抓住观众注意力

**特点：**
- 开篇制造冲突或悬念
- 使用情感化的语言
- 抛出核心问题
- 引发好奇

**示例：**
```
公元975年，金陵城头，南唐后主李煜脸色惨白。城外，宋朝大军围得像铁桶一样。但真正让这位词人皇帝透心凉的，是东南方向传来的战报——盟友吴越国，此刻正发疯一样攻击南唐的后方！

李煜绝望了，他怎么都想不通："唇亡齿寒"的道理，你钱弘俶为什么还要捅我一刀？
```

### 2. 正文内容（约350字）

**作用：** 讲述故事，传递核心观点

**特点：**
- 口语化表达，避免书面语
- 多用短句，节奏感强
- 使用设问句引导思考
- 情感起伏，扣人心弦
- 层层递进，逻辑清晰

### 3. 结尾升华（约50-70字）

**作用：** 总结观点，引发思考

**特点：**
- 回应开头的问题
- 升华主题
- 留有余味

**示例：**
```
历史有时候很幽默。李煜只看到了国与国的博弈，而钱弘俶看到了家与民的存续。有时候，历史上的"背叛"，不过是作为一个弱者，为了活下去，能让更多人活下去，所能做的最悲壮的选择。
```

## 爆款标题生成规则

### 标题特点

1. **制造悬念**：使用疑问句、省略号
2. **情感冲击**：使用强烈情感词汇
3. **数字对比**：使用具体数字增强说服力
4. **反差对比**：表面与真相的反差
5. **字数控制**：10-12个字

### 标题模板

- **疑问式**：XXX？千年真相让人沉默
- **冲突式**：李煜至死不解：为何是你捅刀？
- **反转式**：那一刀背叛，救了整个江南
- **对比式**：被骂千年叛徒，其实是大救星
- **悬念式**：唇亡齿寒？这场算计太狠了

## 输出格式

生成的MD文件包含：

```markdown
# [爆款标题1]

[口播稿正文]

---

## 5个爆款标题供选择

1. [爆款标题1]
2. [爆款标题2]
3. [爆款标题3]
4. [爆款标题4]
5. [爆款标题5]
```

## 注意事项

1. **字数控制**：口播稿控制在450-500字左右（约2分钟口播时长）
2. **口语化**：避免使用过于书面化的表达
3. **节奏感**：多用短句，控制句子长度
4. **情感化**：使用有感染力的语言
5. **逻辑清晰**：起承转合要自然流畅
6. **用词温和**：避免使用敏感词汇和过于血腥暴力的表达
   - 避免使用：杀了、暴毙、弑君、死穴、饿死、灭亡等
   - 替换为：离世/离去、突然离世/英年早逝、不幸离世/不轨行为、致命弱点、受苦、覆灭/崩溃等
7. **平台友好**：确保内容适合视频平台发布，通过审核

## 工作原理

1. **解析文章**：读取MD文件，提取核心内容
2. **智能改写**：
   - 识别文章的核心观点和故事线
   - 提取关键人物和事件
   - 分析情感走向
3. **生成口播稿**：
   - 开头：制造悬念和冲突
   - 正文：口语化改写，保持逻辑清晰
   - 结尾：升华主题，引发思考
   - **敏感词过滤**：自动识别并替换敏感词汇，确保用词温和
4. **生成标题**：
   - 分析文章关键词
   - 生成多个标题选项
   - 优化标题吸引力
5. **保存文件**：写入MD文件，保留格式

| 弑君 | 不轨行为/刺杀 |

## 参数配置

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 字数 | 口播稿字数 | 500字 |
| 标题数 | 生成的标题数量 | 5个 |
| 标题长度 | 每个标题的字数 | 10-12字 |
